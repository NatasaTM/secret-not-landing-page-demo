# Secret Knot – Landing Page Demo

A single-page landing page prototype for a narrative-driven romance & mystery game.

This project demonstrates landing page structure, content hierarchy, and visual design decisions.

---

## Tech Stack

- React 18
- Next.js 15
- TypeScript
- Tailwind CSS

---

## Getting Started

### Prerequisites
- Node.js 18+

### Install and Run

```bash
# Clone the repository
git clone <repository-url>
cd secret-knot-landing-demo

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Build for Production

```bash
npm run build
npm start
```
